# 0.1.6 상세 변경·검증

[기본 릴리스 노트](../RELEASE_NOTES.md) · [English](RELEASE_DETAILS_0.1.6.en.md)

## 변경 사항

GPT-6 Astra + Pro를 기본 웹 대상으로 설정했습니다. 대화 URL을 저장해 요청을 다시 보내지 않고 같은 대화에서 결과를 가져옵니다.

설치기는 새 파일을 임시 폴더에서 복사·해시 검증한 뒤 교체합니다. 교체나 설정 저장 중 처리 가능한 오류가 발생하면 이전 설치로 복구합니다. 성공한 경우에도 이전 설치와 설정 백업을 남기며, 기존 설정 값과 플러그인 순서를 보존합니다.

Windows의 `scripts/diagnose-install.ps1`은 등록 버전, 설치 버전, 실행 중인 Oracle 프로세스를 비교합니다. 불일치하면 재시작을 안내하고, 프로세스를 확인할 수 없으면 미검증으로 표시합니다.

개인 PC 경로를 제거하고 배너·설치 안내를 수정했습니다. Codex 등록 상태는 화면 출력 대신 JSON으로 확인합니다.

## 검증 및 한계

- 실제 Codex에 설치한 0.1.6에서 웹 `6 Pro` 요청, 응답 회수, 대화 URL 저장 및 세션 완료를 확인했습니다.
- Windows 설치·복구 검사와 설정·순서 보존 검사가 통과했습니다.
- 생성 중 강제 중단·복구는 같은 웹 실행 코드를 사용하는 0.1.5에서 검증했습니다.
- macOS 설치 로직은 호스트 검사까지만 완료했습니다. macOS 실제 실행, 네트워크 단절 및 전원 차단 복구는 미검증입니다.
- 전원 차단이나 프로세스 강제 종료 시 자동 복구는 보장하지 않습니다. 이 경우 남겨 둔 백업으로 복구해야 합니다.

## 업데이트

ZIP 체크섬을 확인하고 [설치 안내](AGENT_INSTALL.md)를 따르세요. 설치기가 남긴 백업은 검증을 마칠 때까지 보관하세요. 설치 후에도 이전 MCP가 실행 중이면 Codex 연결을 다시 로드하거나 앱을 재시작하세요.
